# Учебное задание 3: ApiGateway: Маршрутизация запросов

### Цель

* в apigateway сервис добавить запрос из задания номер два, который будет маршрутизировать его на credit-operations сервис
* переделать сохранение данных о пользователе из памяти в базу данных (подумать какие данные хранить в таблице users)
---

## 📌 **Функциональность**

1. ApiGateway принимает запрос от пользователя, и маршрутизирует его на сервис credit-service
2. ApiGateway проверяет роль USER для эндпоинтов пользователя
